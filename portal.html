Revisar pago por transferencia

  1. Consigue el equipo: que pueda enviar las marcaciones a un servidor (API / webhook / "push"). Marcas comunes: ZKTeco, Hikvision, Anviz. Pregúntale al proveedor por esa función antes de comprar.
  2. Registra a cada cliente en el equipo con su ID de equipo: el número de su código (JMP0012 → 12). Lo ves en la ficha del cliente (botón ).
  3. Crea la clave del equipo: en Vercel → Settings → Environment Variables agrega DEVICE_KEY con una clave secreta larga → Redeploy.
  4. Configura el equipo para enviar cada marcación (POST) a:
    con el encabezado x-device-key: (tu clave) y el cuerpo

Privacidad: la huella y el rostro se quedan guardados solo en el equipo; a este sistema únicamente llega el ID del cliente. En Ecuador los datos biométricos se consideran datos sensibles: pide a cada cliente su autorización por escrito antes de registrarlo.
